A workflow is a graph.

- **Trigger**: Manual, webhook, schedule, or block (chain height).
- **Action**: A plugin step such as a Graph query or an ERC-20 transfer.
- **Condition**: Optional branching between actions.

Write actions sign with your linked Privy wallet or org treasury. Read actions do not need a wallet balance.
