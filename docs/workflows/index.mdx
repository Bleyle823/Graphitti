A workflow is a graph.

- **Trigger**: Manual or webhook. There is no scheduler in this release.
- **Action**: A plugin step such as a Graph query or an ERC-20 transfer.
- **Condition**: Optional branching between actions.

Write actions sign with your linked Privy wallet. Read actions do not need a wallet.

## Featured examples

Starred templates (The Graph, Privy, Arc, Circle, Stripe, Telegram, Supabase) are listed first in the app gallery. For credential sources, node placeholders, and what to do when Telegram or notifications fail but core steps succeed, see [Featured example workflows](/workflows/featured-workflows).
