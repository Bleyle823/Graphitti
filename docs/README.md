# Graphitti documentation

Mintlify site for Graphitti: getting started, treasury, plugins, marketplace, and API reference.

## Local preview

Install the [Mintlify CLI](https://www.npmjs.com/package/mint):

```bash
npm i -g mint
```

From this directory:

```bash
mint dev
```

Open the URL shown in the terminal (default port 3000). Configuration is in `docs.json`.

## Published site

Docs deploy from the default branch when Mintlify GitHub integration is connected. The app button in the navbar points to [graphitti-five.vercel.app](https://graphitti-five.vercel.app).
