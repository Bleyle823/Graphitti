---
title: Browser
description: Sign in, connect a Privy wallet, and run your first workflow.
---

<Steps>
  <Step title="Sign in">
    Open the app and click **Sign In**. Better Auth keeps the session. Privy is the wallet layer, not a replacement for sign-in.
  </Step>
  <Step title="Connect wallet">
    Click **Connect wallet** in the auth dialog or user menu. Graphitti creates an embedded EVM wallet and stores it on your user as `user_wallets`.
  </Step>
  <Step title="Create a workflow">
    Add a **Manual** trigger, then an action such as Web3 **Get native balance**.
  </Step>
  <Step title="Run">
    Click **Run**. Open the run panel to read the result. Write actions need a linked wallet and use Privy gas sponsorship.
  </Step>
</Steps>
