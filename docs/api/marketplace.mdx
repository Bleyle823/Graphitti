---
title: Marketplace API
description: Catalog query params, call body, and Circle nanopayment 402 challenges on Arc.
---

Production host: `https://graphitti-five.vercel.app`

Search listed workflows:

```bash
curl "https://graphitti-five.vercel.app/api/mcp/workflows?q=balance&chain=arc&workflowType=read&sort=recent"
```

Call a listing:

```bash
curl -X POST https://graphitti-five.vercel.app/api/mcp/workflows/{slug}/call \
  -H "Content-Type: application/json" \
  -d '{"address":"0x..."}'
```

Paid listings respond `402` with a JSON body and a base64 `PAYMENT-REQUIRED` header:

```json
{
  "x402Version": 2,
  "accepts": [
    {
      "scheme": "exact",
      "network": "eip155:5042",
      "asset": "0x3600000000000000000000000000000000000000",
      "amount": "1000000",
      "maxAmountRequired": "1000000",
      "payTo": "0xCreatorPrivyAddress",
      "maxTimeoutSeconds": 604900,
      "extra": {
        "name": "GatewayWalletBatched",
        "version": "1",
        "verifyingContract": "0x77777777Dcc4d5A8B6E418Fd04D8997ef11000eE"
      }
    }
  ]
}
```

Retry with `PAYMENT-SIGNATURE` set to a base64 JSON payload:

- EIP-3009 `TransferWithAuthorization` signed against the `GatewayWalletBatched` domain
- `validBefore` at least 7 days in the future
- Graphitti settles through Circle Gateway `POST /v1/x402/settle`, then runs the workflow

The buyer address you load is **your EOA** (the wallet whose private key signs). Fund it with Arc ERC-20 USDC (`0x3600000000000000000000000000000000000000`), then **approve and deposit** that USDC into Gateway Wallet `0x77777777Dcc4d5A8B6E418Fd04D8997ef11000eE`. A raw transfer to the Gateway contract does not credit nanopayment balance. `insufficient_balance` means that signer has no Gateway deposit. Listings whose chain is `arc-testnet` still settle on Arc Testnet (`eip155:5042002`, Gateway `0x0077777d…`).

Paid listings always return `402` on `GET` or `POST` `/api/mcp/workflows/{slug}/call` until a valid `PAYMENT-SIGNATURE` is sent. Catalog `GET /api/mcp/workflows` and `GET .../listing` stay `200` and are not payable.

Pay any listing from the repo:

```bash
cd graphitti
pnpm pay-listing -- https://graphitti-five.vercel.app/api/mcp/workflows/{slug}/call
```

Set `PRIVATE_KEY` in `.env.local`. The script prints `transaction` (Circle settlement id / hash when Gateway returns one), `paymentId`, `nonce`, and `executionId`.

Agents do not send API keys or invoices. Graphitti records `workflow_payments` by SHA-256 hash so retries are idempotent.
