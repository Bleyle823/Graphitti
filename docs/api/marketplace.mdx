---
title: Marketplace API
description: Catalog query params, call body, and the Arc 402 challenge.
---

Search listed workflows:

```bash
curl "https://<host>/api/mcp/workflows?q=balance&chain=arc-testnet&workflowType=read&sort=recent"
```

Call a listing:

```bash
curl -X POST https://<host>/api/mcp/workflows/{slug}/call \
  -H "Content-Type: application/json" \
  -d '{"address":"0x..."}'
```

Paid listings respond `402` with `PAYMENT-REQUIRED`:

```json
{
  "accepts": [
    {
      "scheme": "exact",
      "network": "eip155:5042002",
      "asset": "0x3600000000000000000000000000000000000000",
      "maxAmountRequired": "1000000",
      "payTo": "0xCreatorPrivyAddress"
    }
  ]
}
```

Retry with `PAYMENT-SIGNATURE`. Graphitti records `workflow_payments` by SHA-256 hash so retries are idempotent.
