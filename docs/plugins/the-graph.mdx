Use `THEGRAPH_API_KEY` for gateway GraphQL and Token API. Use `SUBSTREAMS_API_KEY` only for the Substreams data plane. Market reads need a stored Portal bearer.

Discovery never introspects schema unless you run **Get schema**. Query outputs include `query_url` and `query_url_x402`. **Never auto-pay** Graph x402 from a step.

| Group | Actions |
|---|---|
| Discovery | Search, recommend, detail, schema, find by contract |
| Query | Query subgraph, indexing status, lending snapshot |
| Token API | Balances, transfers, holders, DEX swaps, NFT activity |
| Substreams | Search packages, get package, default endpoint |
| Market | Subscription, usage, bill, connections, hosted deployments |
