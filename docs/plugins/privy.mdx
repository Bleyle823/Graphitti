Credentials: `PRIVY_APP_ID`, `PRIVY_APP_SECRET`.

For Eliza, OpenClaw, Hermes, and Eve agent runtimes, see [Privy agent plugins](/plugins/agent-privy).

| Action | Outputs |
|---|---|
| Get user | Privy user and linked accounts |
| List / create / get wallet | Wallet id and address |
| Send sponsored transaction | Transaction hash |
| Sign message / typed data | Signature |
| Transfer | Sponsored send |
| Get transaction | Wallet transaction status |
