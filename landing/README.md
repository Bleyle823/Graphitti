# Graphitti landing

Marketing Next.js site for Graphitti. The workflow product runs in [`graphitti/`](../graphitti/) at [graphitti-five.vercel.app](https://graphitti-five.vercel.app).

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port shown if 3000 is in use).

## Build

```bash
pnpm build
pnpm start
```
